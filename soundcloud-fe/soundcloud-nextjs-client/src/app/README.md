# robots.txt => file này nói với các con bot search engine của các ông lớn gg, fb, ms, ... đi đào dữ liệu > mục đích để nói file nào được đào dữ liệu, file nào không nên => file này chỉ mang tính chất tương đối

# sitmap.xml => file này để nói với các con bot
+ đường link nào quan trọng nên ưu tiên
+ đường link nào kém ưu tiên

=> 2 file trên mục đích giúp con bot đánh giá website của mình tốt hơn

# manifest.json => file này tương tự như thêm file apple-icon => tăng trải nghiệm người dùng (không phải SEO)

(VD: tiki dùng nextjs 12 có các công nghệ trên)

# json-ld: (Link Data)
JSON-LD dùng để cung cấp dữ liệu có cấu trúc (structured data) cho search engine (Google, Bing, …) hiểu rõ nội dung trang của bạn hơn
human view HTML, machine can't HTML
=> JSON thân thiện cho human, machine (kết nối giữa page cho bot đào dữ liệu => mất khá lâu để bot đào đến website khoảng vài tháng)
